# DevTools Exploration

## Website 1: example.com
- HTML tags: - `<html>`, `<head>`, `<title>`, `<body>`
- `<div>`, `<h1>`, `<p>`, `<a>`
- Page title: **Example Domain**
- Headings: **1 heading**(`<h1>`).
 
## Website 2: MDN
- Nav tag: `<nav>` element.

- Search bar: The search bar is inside a `<form>` element containing:
- `<label>` for accessibility
- `<input type="search">` for the search field
- `<button type="submit">` for submitting

- Hover styles: links change color and get an underline e.g ;
  css
a:hover {
    text-decoration: underline;
  }

### Website 3: https://github.com

#### 5 Different HTML Elements Identified
- `<header>` — top navigation bar
-  `<nav>` — menu links
-  `<main>` — main content area
-  `<article>` — repository cards
-  `<footer>` — page footer

  ### Form Element
  | Input type | Purpose |
  
| `type="text"` | Search query |
| `type="submit"` | Submit button |
